# Responsive Navbar with Hamburger Menu

A simple, responsive navigation bar built using HTML, CSS, and JavaScript as part of my web development
learning journey.

##Features

- Responsive navigation bar for desktop and mobile screens
- Hamburger menu for mobile navigation
- Animated hamburger-to-cross transition
- Smooth CSS transitions and hover effects
- Navigation menu that opens and closes on click
- Automatically closes the mobile menu when a navigation link is clicked

## Technologies Used

- **HTML5** — Structure of the navigation bar
- **CSS3** — Styling, Flexbox, media queries, and animations
- **JavaScript** — Hamburger menu toggle functionality

##Project Structure
responsive-navbar/
├── index.html

## How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Resize the browser window to test the responsive layout.
5. Click the hamburger icon on smaller screens to open the navigation menu.

## What I Learned

- How to create a responsive layout using CSS Flexbox
- How to use media queries for mobile-friendly designs
- How to manipulate CSS classes using JavaScript
- How to animate a hamburger menu into a cross icon
- How to create smooth transitions with CSS
